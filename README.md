# sql-sales-analysis
SQL project analyzing sales data using joins and aggregations

## Project Overview
This project analyzes sales data using SQL joins and aggregations to extract business insights, including revenue, top-selling products, and customer behavior.

## Skills Demonstrated
- SQL Joins (INNER JOIN)
- Aggregations (SUM, COUNT)
- GROUP BY and HAVING clauses
- Business-oriented data analysis

## Database Tables
- customers
- products
- orders
- order_items

## Key Insights
- Identified top revenue-generating customers
- Analyzed best-selling products
- Calculated revenue by category
- Observed monthly sales trends

## Tools
- SQL (PostgreSQL / MySQL)
